Esse código facilita inserir informações de uma biblioteca de livro pessoal e cria um arquivo em excel para facilitar a visualização de seus livros.

Para isso. basta escrever o Nome, Ano de publicação e o Autor de cada um de seus livro.

Quando acabar de passar as informações de todos os seus livros, basta escrever a palavra "fim" que o código irá se encerrar e o arquivo excel será gerado!
